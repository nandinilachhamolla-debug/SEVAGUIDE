# SEVAGUIDE 🎓

A scholarship guidance and discovery prototype designed to help
students identify potentially relevant education scholarship
opportunities based on basic information.

## Problem

Students often struggle to discover scholarships that may be
relevant to their education level and state.

## Solution

SEVAGUIDE provides a simple guided questionnaire that helps students
identify potential scholarship opportunities.

## Features

- Education-level based matching
- State-based filtering
- Scholarship recommendation cards
- Eligibility information
- Document checklist
- Accessibility-focused interface
- Simple guided user flow
- Prototype disclaimer for synthetic data

## User Flow

Home
↓
Enter basic details
↓
Select education level
↓
Select state
↓
Find potential matches
↓
View scholarship details
↓
Check eligibility and documents
↓
Verify official requirements

## Technology

- HTML
- CSS
- JavaScript
- Node.js / Express.js for local prototype backend
- GitHub Pages for frontend deployment

## Important Notice

This is a prototype using synthetic demonstration data.
Users must verify scholarship eligibility and current requirements
through official sources before applying.
